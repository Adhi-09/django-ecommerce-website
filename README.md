# Django E-Commerce Website

A simple e-commerce web application developed using the Django framework. The project demonstrates the basic functionality of an online shopping platform, including product browsing, user authentication, shopping cart management, and order placement.

## Features

* User Registration and Login
* Product Listing
* Product Details Page
* Shopping Cart
* Checkout Process
* Order Management
* Admin Dashboard
* Responsive User Interface

## Technologies Used

* Python
* Django
* HTML5
* CSS3
* JavaScript
* SQLite

## Installation

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/<repository-name>.git
```

2. Navigate to the project folder:

```bash
cd <repository-name>
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Apply migrations:

```bash
python manage.py migrate
```

5. Run the development server:

```bash
python manage.py runserver
```

6. Open your browser and visit:

```
http://127.0.0.1:8000/
```
